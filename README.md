# antibody

Give it any US federal bill. It shows the headline fight, what got buried underneath it, who lobbied for it and funded it, who benefits, and which members of Congress hold or traded stock in the companies that win.

Every claim links to a public source. Inferences are labeled as inferences. The same rules apply to every party.

```sh
bun install
bun run antibody xray S.1582
```
